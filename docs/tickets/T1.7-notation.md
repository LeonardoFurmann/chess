## Objetivo

Converter lances internos para as notações usadas pela UI (SAN), pela persistência e pelo protocolo da IA (UCI).

## Escopo de arquivos

- `src/engine/core/notation.ts`
- `src/engine/core/notation.test.ts`

## O que fazer

- `moveToUci(move)`: `e2e4`, `e7e8q`, roque como movimento do rei (`e1g1`).
- `uciToMove(pos, uci)`: localiza o lance **legal** correspondente; `null` se não existir ou se o texto for malformado.
- `moveToSan(pos, move)` (antes de o lance ser aplicado): letra da peça, desambiguação mínima (coluna; se não bastar, fileira; se não bastar, ambas), `x` em captura (peão inclui coluna de origem), `=Q`/`=R`/`=B`/`=N`, `O-O` / `O-O-O`, sufixo `+` ou `#`.

## Critérios de aceite

- [ ] SAN de **todos os lances legais** coincide com o `chess.js` em todas as posições de `random-positions.ts`.
- [ ] Casos explícitos: `Nbd2`, `R1e2`, `Qh4e1` (três damas), `exd6` (en passant), `e8=Q+`, `O-O-O#`.
- [ ] `uciToMove` ∘ `moveToUci` é identidade para todos os lances legais das fixtures; `uciToMove` retorna `null` para `e2e5` na posição inicial, para `e7e8` sem peça de promoção e para strings como `zz99`.
- [ ] `moveToSan` não altera a posição (hash e FEN iguais antes e depois).

## Para o verificador

Desambiguação em que uma das peças está cravada (não deve contar), promoção a cavalo com xeque, roque que dá xeque.
